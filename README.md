# 视觉小说翻译器

给自己做的视觉小说翻译工具。填一个 DeepSeek 的 API key 就能用，选好游戏点一下，翻完直接进游戏玩中文版。

- Ren'Py 视觉小说：整本批量翻译，装成补丁。补丁不改游戏原文件，删掉就恢复原样。
- Unity 游戏：边玩边翻，翻过的句子存下来，下次不再花钱。
- 目前只翻成简体中文。
- 默认用 DeepSeek，也能填其他兼容 OpenAI 接口的服务；会显示 tokens 用量和花了多少钱。

## 下载使用（Windows）

1. 到 [Releases](../../releases/latest) 下载 `VNTranslator-windows-x64.zip`
2. 解压，双击「启动.bat」
3. 「设置」里填 DeepSeek API key，选游戏文件夹，勾上游戏点「翻译勾选的游戏」

自带 Python 运行时，不用另外装。

## 说明

- API key 只存在本机工具文件夹的 `config.json` 里，不会上传。
- 翻译记录在 `data/`，用量在 `用量记录.csv`。
- 个人自用工具，游戏文本版权归原作者。

## v1.0.1 修复

- 可直接添加单个游戏目录；游戏根目录本身也会显示在列表里。
- Unity 安装采用临时文件写入，失败后可重试补齐；已有翻译插件的配置会备份，点「还原」恢复原配置。
- Unity 缓存按原文语言区分，并采用插件请求中的语言。旧版工具缓存原文件保留；游戏内已有译文继续使用，不会因为升级自动清空。
- Ren'Py 支持韩文，并自动识别包含假名的日文游戏；纯汉字日文或繁体中文请选择「Ren'Py 原文」，再刷新或翻译。
- TextMeshPro 显示方块时，可用「选 TMP 字体包…」选择与该游戏 Unity/TMP 版本匹配的中文资产包。安装或从工具启动时会复制并配置；系统 ttf/ttc 文件不能代替旧版 TMP 资产包。不选时保留原有 TMP 字体设置，「取消 TMP 字体包」会在下次启动时恢复安装前的设置。

TMP 字体的制作和兼容要求见 [XUnity 字体说明](https://github.com/bbepis/XUnity.AutoTranslator/tree/v5.6.2#changing-fonts)。本工具不自动下载通用 TMP 字体包，不同游戏需要的版本可能不同。

旧版 v1.0.0 已经覆盖且没有备份的插件设置无法凭空找回；本次备份从第一次使用 v1.0.1 修改设置前开始。旧工具缓存不含原文语言，所以升级后不猜测其语言；若游戏缓存中没有某句，新版会按当前原文语言重新翻译。

## 开发验证

`python -m unittest discover -s tests -v` 使用临时游戏目录与模拟 API 验证安装/还原、失败重试、语言缓存、文本提取和字体配置，不调用付费接口。PR 会运行回归测试和 Windows 打包自检，合并到 main 后按 VERSION 发布。
